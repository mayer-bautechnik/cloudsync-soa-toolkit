# cloudsync-soa-toolkit
PowerShell toolkit for Microsoft Entra Cloud Sync (Entra ID → AD provisioning) with AD object enforcement: keeps cloud-only and SOA-converted users passwordless (WHfB/FIDO2 via Cloud Kerberos Trust, AVD SSO) using SCRIL, DC-native secret rolling and a PSO, with per-DC event-driven onboarding, monitoring, tests and step-by-step rollback.
