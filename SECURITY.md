# Security policy

The toolkit runs with high privileges (Domain Admin during setup, an allow-listed gMSA on Tier-0 hosts at runtime). Please report security-relevant findings **privately** through GitHub private vulnerability reporting (repository tab *Security* → *Report a vulnerability*: https://github.com/mayer-bautechnik/cloudsync-soa-toolkit/security). Do not open a public issue.

Please include the toolkit version, the affected script / step, and a description of the impact. Remove all identifying data of your environment.

Findings that concern Microsoft products (Entra Cloud Sync, AD object enforcement, Windows) belong to the Microsoft Security Response Center (https://msrc.microsoft.com/).

Supported versions: the latest release (2.x).
